# Include Directory

This directory contains header files and configuration files.

## Files

- `config.h` - Configuration file (create from config.h.example)
- `config.h.example` - Template configuration file

## Setup

1. Copy `config.h.example` to `config.h`
2. Update all configuration values in `config.h`
3. **DO NOT** commit `config.h` to version control (it contains sensitive data)

## Configuration Values

- WiFi SSID and password
- Server URL
- Organisation Object ID
- Device ID
- Pin assignments
- Timing parameters
